# About KittiSU

## What is KittiSU? {#what-is-kittisu}

A downstream fork of [ReSukiSU](https://github.com/ReSukiSU/ReSukiSU) (based on SukiSU Ultra) that removes obsolete or unnecessary components, with a focus on stability and ease of building.

## Project Aim {#the-aim}

To provide a more stable and reliable kernel-based root solution for Android — that's all.

## Features {#features}

- **KernelSU-Based Root** — Kernel-based `su` and root management with multi-backend support (KernelSU, RKSU, MKSU, SukiSU)
- **Metamodule System** — Systemless module management for modifications
- **App Profiles** — Granular root access restriction per application
- **Non-GKI Support** — Full support for Non-GKI and GKI 1.0 devices
- **KPM Support** — Experimental KernelPatch Module support
- **Built-in SuSFS Management** — Advanced security control
- **Multi-Manager Compatibility** — Works with Official KernelSU, RKSU, MKSU, and SukiSU managers

## Why Was This Project Created? {#why}

Due to issues with ReSukiSU's code maintenance and community engagement, coupled with the need for a more actively maintained fork with cleaner code practices, we initiated this project to provide a more stable and collaborative alternative.
