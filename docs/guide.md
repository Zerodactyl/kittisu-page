# Guide

Welcome to KittiSU — a kernel-based root solution for Android, forked from ReSukiSU with a focus on stability and ease of use.

## Getting Started

### Prerequisites

- An Android device with an unlocked bootloader
- Custom recovery (recommended) or fastboot access
- Basic knowledge of Android modding

### Installation

1. **Download the Manager APK** from the [Releases](https://github.com/terebiko/KittiSU/releases) page.
2. **Flash the kernel** via your custom recovery or using the built-in flash method in the Manager app.
3. **Reboot** and enjoy root access.

> [!WARNING]
> Rooting your device may void its warranty. Proceed at your own risk.

## Compatibility

| Feature | Status |
|---------|--------|
| Android GKI 2.0 (kernel 5.10+) | ✅ Officially supported |
| Older kernels (3.4+) | ✅ Buildable manually |
| SuSFS backport | ✅ Supported from kernel 4.3+ |
| Tracepoint Syscall Redirect | ✅ Supported on GKI2 (5.10+) |
